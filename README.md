# Re:Nrob Lab 訂單管理

管理新單、打樣、生產大貨與內部帳務。灣得入口為公開唯讀，內部管理必須登入。

## 本機使用

雙擊 `start.command`，在瀏覽器開啟 http://127.0.0.1:8765 。

若直接開啟 `web/index.html`，頁面會轉到上述本機網址。請保持本機服務執行；若瀏覽器禁止檔案自動跳轉，可按頁面上的「開啟本機網站」。

- 內部管理：`/`，初始密碼記錄在 `data/本機登入資訊.txt`。可在「工作空間設定」變更。
- 公開唯讀：`/factory`。本機網址只能在本台電腦使用。
- 訂單紀錄：`data/orders.sqlite3`。
- 新單自動建立「訂單號 代號」資料夾。資料夾已存在時不會覆寫。
- 已存在的訂單可以用 `import_existing.py` 明確匯入，原始文件保持不變。
- 編輯時若另一個視窗已修改同一訂單，系統會要求重新整理，避免覆蓋。
- 訂單號與代號建立後固定，以維持原始資料夾連結。

## 在其他電腦安裝

Python 3.11 或更新版本：

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python setup_local.py --orders-root '/absolute/path/to/orders' --template '/absolute/path/to/template.xls'
.venv/bin/python server.py
```

`setup_local.py` 只讀取參考範本並建立本機設定。它不會把客戶資料或密碼寫入程式碼。

## 權限

公開介面由伺服器以欄位白名單輸出，與內部 API 分開。隱私保護不是只靠畫面隱藏。

| 公開（灣得可見） | 內部管理 |
| --- | --- |
| 訂單號、代號、款號、顏色、數量 | 客戶單價、是否開發票、稅別、運費 |
| 需求、製作規格、印花、包裝 | 定金、尾款、收款狀態、銷項發票 |
| 打樣階段、樣品交期、樣品確認 | PI 買方資料、PI 檔案、工廠報價、內部備註 |
| 大貨狀態、交期 | 本機路徑、所有未明確公開的檔案 |
| 打樣請款單、進項發票號碼與付款狀態 | 登入、訂單修改、上傳、備份 |

上傳時選擇「設計圖稿」「打樣請款單」「打樣進項發票」的附件會公開提供下载。既有資料夾內的檔案預設全部為內部，避免意外公開未分類文件。

## PI

1. 在訂單資料夾放入工廠報價 PDF，或透過「加入檔案 → 工廠報價」上傳。
2. 「讀取工廠報價」會顯示可擷取的 PDF 文字，供核對規格；掃描圖片 PDF 需人工查看。
3. 在「編輯訂單」填入客戶售價、規格、買方資訊。工廠成本不會自動變成客戶售價。
4. 「製作 PI」會產生新版本並存回該訂單資料夾。

原始 `.xls` 範本最多容納 6 筆顏色明細。6 色以內會保留範本版型輸出 `.xls`，所有訂單另產生完整可列印的 `.html` PI。超過 6 色時產生完整 HTML PI；可在瀏覽器列印或另存 PDF。每份 PI 都保留舊版本。

Excel 的數量、小計、稅金與總額使用公式，開啟檔案時由 Excel 計算。已測試輸出檔案、公式結構、合併儲存格、欄寬與來源範本不被更動。尚未完成原生 Excel 重算與視覺檢查，首次正式寄出前請檢視生成的 PI。

原始範本不包含在公開程式庫，買方、銀行資料與條款保存在本機私有設定中。重新部署時需自行配置範本與私有設定。

## 上傳 GitHub 與公開上線

此程式庫可上傳至 `gotaorange` 的 GitHub。`data/`、附件、密碼、資料庫與個人檔案不可加入 Git。

### 給同事檢視的介面預覽

執行 `python3 scripts/build_review.py` 會建立 `preview-dist/` 靜態預覽，僅包含介面和三筆虛構示範訂單。可切換內部介面及灣得可見範圍，檢視欄位、版面與流程；不連接真實資料、不儲存修改，也不會上傳文件、製作 PI 或變更密碼。

GitHub Pages 工作流程會檢查並發布這個示範版本。配色為白底黑字、淺灰與黑色色塊，紅色只用於關鍵文字。GitHub 倉庫需將 Pages 的發布來源設為 GitHub Actions。

### 正式訂單系統

GitHub Pages 只能提供靜態網頁，無法執行正式系統的登入與資料儲存服務。

正式使用需要 HTTPS 反向代理與可持續儲存資料的 Python 主機。`Dockerfile` 提供部署封裝；設定下列環境變數：

| 變數 | 用途 |
| --- | --- |
| `HOST` | 本機預設 `127.0.0.1`；容器使用 `0.0.0.0` |
| `PORT` | 預設 `8765` |
| `PUBLIC_ORIGIN` | 正式 HTTPS 網址，不含結尾斜線 |
| `ADMIN_PASSWORD` | 至少 12 個字元，使用主機的秘密變數功能提供 |
| `RENROB_DATA` | 私有資料與 SQLite 的持久儲存目錄 |
| `RENROB_ORDERS` | 附件與訂單資料夾的持久儲存目錄 |
| `RENROB_PI_TEMPLATE` | 私有 `.xls` 範本的完整路徑 |

容器需掛載 `/data` 持久磁碟，不可將私有資料放入映像或 GitHub。`ADMIN_PASSWORD` 設定時，密碼須在主機端更新；登入 Cookie 以 Secure、HttpOnly、SameSite=Strict 保護。

網站在外部主機上執行時，無法直接讀寫使用者 Mac 桌面。若要保持指定的 Mac 資料夾為唯一儲存來源，需要讓 Mac 服務保持運作並搭配 HTTPS 入口；若改用雲端主機，需要另規劃資料搬移與同步。本版本尚未部署，也未建立這種同步。

公開部署時還需要服務的流量限制、資料備份與監控；內建伺服器以本機與小規模使用為範圍。

## 測試

```sh

node tests/test_startup.mjs
```

測試在隔離暫存目錄建立訂單，驗證登入、公私資料隔離、路徑檢查、重複訂單、進度前置條件、附件公開範圍、PI 輸出與待補資料訂單。Excel 範本測試在本機範本設定存在時執行。
